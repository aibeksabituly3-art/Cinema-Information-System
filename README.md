# Cinema-Information-System
# Кинотеатрдың ақпараттық жүйесі

## 1. Жоба туралы
Бұл жоба кинотеатр жұмысын автоматтандыруға арналған.

## 2. Жобаның мақсаты
Фильмдер, киносеанстар және билеттер туралы ақпаратты басқару.

## 3. Негізгі функциялары
- Фильмдер тізімін көру
- Фильм туралы ақпарат алу
- Киносеанстарды қарау
- Билет брондау
- Фильмдер мен сеанстарды басқару

## 4. Пайдаланушылар
- Көрермен
- Әкімші

## 5. Қолданылатын технологиялар
- Git
- GitHub
- Markdown
- UML

## 6. Жоба құрылымы
- docs/requirements.md — жүйеге қойылатын талаптар
- docs/use-case.md — пайдалану сценарийлері
- docs/diagrams/ — UML диаграммалары

## 7. Нұсқаларды басқару
Жоба Git және GitHub арқылы басқарылады.
