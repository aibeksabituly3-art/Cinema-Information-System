# Кинотеатрдың ақпараттық жүйесі — Use Case

## Көрермен
- Фильмдер тізімін қарау
- Фильм туралы ақпарат алу
- Киносеансты таңдау
- Билет брондау

## Әкімші
- Фильм қосу
- Фильм туралы ақпаратты өзгерту
- Фильмді өшіру
- Киносеанстарды басқару

## Билет брондау сценарийі
1. Көрермен жүйені ашады.
2. Фильмді таңдайды.
3. Сеансты таңдайды.
4. Билет брондайды.
5. Жүйе брондау нәтижесін көрсетеді.
