# Жүйеге қойылатын талаптар

## Функционалдық талаптар
1. Фильмдер тізімін көрсету.
2. Фильм туралы ақпарат беру.
3. Киносеанстарды көрсету.
4. Билет брондау.
5. Фильмдер мен сеанстарды басқару.

## Пайдаланушылар
- Көрермен
- Әкімші

## Функционалдық емес талаптар
1. Интерфейс түсінікті болуы керек.
2. Ақпарат дұрыс сақталуы керек.
3. Жүйе қауіпсіз болуы керек.
